<h3 align="center">LLM-driven evolution of prompts and pipelines</h3>

<p align="center">
  Hand it a labeled dataset and a pipeline. It evolves the prompt <b>and</b> the pipeline's parameters together,<br>
  cuts a losing candidate the moment the evidence says it will not win, and shows every measurement behind the winner.
</p>
